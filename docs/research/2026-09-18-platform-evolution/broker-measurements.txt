Note on the two size figures
----------------------------
`on-disk-uncompressed-bytes` (the image manifest's layer sum) and `docker images` SIZE disagree for
the same tag — e.g. nats:2-alpine reports 11 142 909 bytes (~10.6 MB) as a layer sum and 40.6 MB in
`docker images`. Both are recorded above rather than picking one; the ranking between brokers is
identical either way, which is all the note relies on. The precise reason for the divergence on this
Docker Desktop version was not investigated (UNVERIFIED).
